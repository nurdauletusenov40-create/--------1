# PersonalProfileApp

## Жобаның мақсаты

PersonalProfileApp — студент туралы ақпаратты және оқу жобаларын көрсететін ASP.NET Core MVC негізіндегі жеке визитка сайты. Жоба университеттің бірінші апталық зертханалық жұмысына арналған.

## Студент туралы мәлімет

- **Аты-жөні:** Үсенов Нұрдаулет
- **Университеті:** Абай атындағы Қазақ ұлттық педагогикалық университеті
- **Тобы:** ИСК-242
- **Курсы:** 3-курс
- **Қаласы:** Шымкент
- **Бағыты:** Ақпараттық жүйелер
- **Қызығушылықтары:** бағдарламалау, веб-әзірлеу, киберқауіпсіздік және IT технологиялары

## Қолданылған технологиялар

- C# және .NET 8.0
- ASP.NET Core MVC және Razor Views
- HTML5, CSS3 және локалды Bootstrap 5
- Visual Studio 2022 немесе Visual Studio Code

Сыртқы NuGet кітапханалары, дерекқор, тіркелу немесе авторизация қолданылмайды. Bootstrap файлдары `wwwroot/lib/bootstrap` бумасында орналасқан, сондықтан сайттың негізгі беттері интернетсіз де ашылады.

## MVC архитектурасы

- **Model:** `Models/StudentProfile.cs` студенттің деректерін және портфолио жобаларын сипаттайды.
- **Controller:** `Controllers/InfoController.cs` модельді дайындап, тиісті көріністерге жібереді.
- **View:** `Views/Info` ішіндегі Razor беттері модель деректерін экранға шығарады.

`Program.cs` әдепкі маршрутты `/Info/Index` бетіне бағыттайды. `/` және `/Info` мекенжайлары да осы бастапқы бетті ашады.

## Visual Studio 2022 арқылы ашу

1. Visual Studio 2022 орнатқышынан **ASP.NET and web development** жұмыс жүктемесін орнатыңыз.
2. `PersonalProfileApp.sln` файлын Visual Studio 2022 арқылы ашыңыз.
3. Қажет болса, Visual Studio ұсынған NuGet пакеттерін қалпына келтіру әрекетін орындаңыз.
4. `PersonalProfileApp` жобасын іске қосу жобасы етіп таңдап, **F5** немесе **Ctrl+F5** пернелерін басыңыз.

Жоба .NET 8 SDK және ASP.NET Core 8 runtime талап етеді.
`global.json` жобада .NET 8 SDK-ның орнатылған patch-нұсқасын таңдайды; бұл Visual Studio мен командалық жолда бірдей SDK қолдануға көмектеседі.

## Командалық жолдан іске қосу

Жоба бумасында терминал ашып, мына командаларды орындаңыз:

```powershell
dotnet restore
dotnet build
dotnet run
```

Терминалда көрсетілген жергілікті мекенжайды браузерде ашыңыз. Қосымша әдепкіде `/Info/Index` бағытына өтеді.

## Негізгі беттер

- `/Info` немесе `/Info/Index` — студенттің қысқаша таныстырылымы.
- `/Info/About` — оқу деректері, дағдылар, қызығушылықтар және байланыс ақпараты.
- `/Info/Portfolio` — оқу жобалары және қолданылған технологиялары.

Байланыс деректері берілмегендіктен, email, телефон немесе әлеуметтік желі сілтемелері ойдан қосылған жоқ.
